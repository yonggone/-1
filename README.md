# 2-4반 게시판 앙!

이 폴더에서 `bash '게시판 시작.sh'` 또는 `python3 server.py`를 실행하고 http://127.0.0.1:8080 에 접속하세요. Python 3.9 이상과 Pillow가 필요합니다(현재 컴퓨터에는 설치되어 있습니다). 다른 컴퓨터에서 Pillow가 없으면 `python3 -m pip install Pillow`로 설치하세요. 로그인 기능을 위해 HTML 직접 열기나 `python3 -m http.server` 대신 이 서버로 실행해야 합니다.

모바일에서는 컴퓨터와 같은 네트워크에 연결한 뒤 `http://컴퓨터의IP주소:8080`에 접속하세요. 같은 서버에 접속한 기기들은 계정과 프로필을 공유합니다. 현재 서버는 로컬 네트워크용이며 인터넷 공개 시 HTTPS와 운영 서버 설정이 필요합니다.

- 학생 계정: 20401~20436 중 20408, 20433 제외한 34명. 초기 비밀번호 `1234`.
- 선생님 아이디: `강경민`. 초기 비밀번호는 요청한 값으로 서버에서 설정합니다.
- 모든 계정은 첫 로그인 직후 새 비밀번호(8~128자)를 설정해야 합니다. 변경을 마쳐야 게시판과 프로필을 사용할 수 있습니다.
- 왼쪽 위 사람 아이콘으로 내 프로필에 들어갑니다. 생일(월/일)과 인스타 아이디를 저장하거나 지울 수 있으며 입력은 선택 사항입니다.
- 로그인한 반 친구들은 프로필 목록을 볼 수 있습니다. 각 계정은 자기 프로필만 수정할 수 있습니다.
- 프로필에서 로그아웃 또는 비밀번호 변경이 가능합니다. 이후 변경에는 현재 비밀번호가 필요합니다.
- 비밀번호는 scrypt 해시로 저장합니다. HttpOnly 세션 쿠키는 12시간 유효하며 서버 재시작 시 다시 로그인해야 합니다. 비밀번호 변경 시 해당 계정의 다른 세션은 만료됩니다.
- 계정과 프로필은 `.data/board.sqlite3`에 저장되어 재시작해도 유지됩니다. 개인정보가 담긴 파일이므로 공유하거나 저장소에 올리지 마세요. 삭제하면 모든 계정이 초기화됩니다.

- 화살표: 이전/다음 달 이동 (연도 자동 전환)
- 날짜: 해당 날짜 일정 보기, 다시 누르면 월 전체 보기
- 오늘: 현재 월과 오늘 날짜로 이동
- 일정 항목: 해당 일정 시작일 선택
- 일정 수정: `app.js` 상단의 `events` 목록 수정

첨부 이미지에 따라 2026년 9월부터 2027년 2월까지 일정을 옮겼습니다. 범위 일정은 모든 해당 날짜에 표시되며, 9월 28일~10월 2일 시험은 두 달 모두에서 볼 수 있습니다. 이미지에 없는 일정은 추가하지 않았습니다.

수행평가 메뉴의 글쓰기로 제목(100자), 과목(30자), 시행 날짜, 내용(8000자)을 작성할 수 있습니다. 로그인과 최초 비밀번호 변경을 마친 학생과 선생님 모두 작성·조회할 수 있으며, 작성자는 서버에서 현재 로그인 계정으로 기록합니다.

사진첩 메뉴에서는 JPG/PNG/WebP 사진(한 장 최대 10MB, 최대 2500만 픽셀)과 선택 설명(140자)을 올릴 수 있습니다. 폴라로이드 형태로 표시하고, 원본 비율을 유지해 사진 전체를 보여줍니다. 게시물과 사진은 데이터베이스에 저장되어 재시작해도 유지됩니다. 사진이 쌓이면 데이터베이스 용량도 커지므로 백업 시 `.data` 폴더를 함께 보관하세요.

사진 원본은 서버에서 선생님 역할을 검사하는 다운로드 경로로만 제공됩니다. 학생은 최대 640px의 축소·재인코딩된 미리보기만 볼 수 있고 선생님에게만 원본 다운로드 버튼이 표시됩니다. 학생이 원본 주소를 직접 입력해도 403으로 차단합니다. 로그인하지 않으면 미리보기도 제공하지 않습니다. 브라우저에 표시되는 미리보기의 저장과 화면 캡처 자체는 차단할 수 없습니다.

검증: `python3 -m unittest -v test_server.py` (실제 계정과 분리된 임시 데이터베이스 사용).

로그인 후 첫 화면의 달력(학사일정), 종이(수행평가), 폴라로이드(학급앨범) 버튼으로 화면을 이동합니다. 위쪽 메뉴의 처음 화면으로 돌아갈 수 있습니다. 전체 화면은 칠판 바탕과 테이프로 붙인 종이 디자인을 사용합니다.

프로필에서 이름(선택, 최대 20자)도 설정할 수 있습니다. 이름은 친구 목록과 게시물 작성자에 학번과 함께 표시됩니다. 기존 데이터베이스는 서버 시작 시 이름 칼럼과 게시판 테이블만 추가하므로 계정과 변경한 비밀번호를 유지합니다.
